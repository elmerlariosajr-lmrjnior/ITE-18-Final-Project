# Eco Rescue Ranger

## Project Story & Concept
Eco Rescue Ranger is a first-person environmental mission game where the player must help restore a damaged ecosystem before time runs out. You must collect and sort trash, repair leaking pipes, and rescue lost deer within a limited time. The game encourages environmental awareness through interactive tasks, real-time objectives, and urgency-based gameplay.

## Development Stack
*   **Frontend:** A-Frame (Web-based 3D framework)
*   **Languages:** HTML, CSS, JavaScript
*   **Assets Used** 3D models (GLB), textures (JPG/PNG), and sound effects (MP3)

## Setup Instructions
1.  **Download the Project:** Make sure the full project folder is on your computer.
2.  **Open in VS Code:** Open the project folder in Visual Studio Code.
3.  **Run with Live Server:** 
        •Install the Live Server extension in VS Code.
        •Right-click index.html
        •Click “Open with Live Server”
4.  **Play the Game:** The browser will open automatically (example: http://127.0.0.1:5500/).
